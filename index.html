For agents

The plots on this page are <canvas> renderings. There is no DOM text to scrape and no way to recover a number from the pixels. An AI agent connected over WebMCP does not have to try: this page registers site tools that hand back the simulation output itself — overshoot, rise and settling time, steady-state error, gain and phase margin, closed-loop pole locations.

The same tools set the controller gains and the plant, and every write returns the resulting metrics, so an agent can close the tuning loop: adjust, measure, adjust again. You watch the curves move while it works, and you can take any slider back at any moment.
